# Security Policy

## Supported versions

Zebra AI is under active development. Security fixes are applied to the latest
code on the `main` branch; older commits and deployments are not supported.

## Reporting a vulnerability

Please do not report vulnerabilities in a public issue, discussion, pull
request, or social post.

Use GitHub's **Security** tab and select **Report a vulnerability** to submit a
private vulnerability report to the maintainers. Include:

- A concise description and the affected component or route.
- Reproduction steps or a minimal proof of concept.
- The impact you believe is possible.
- Any suggested mitigation, if known.
- Whether the issue has been disclosed anywhere else.

If private vulnerability reporting is unavailable, contact the repository
owner, [@Bishu-21](https://github.com/Bishu-21), through the private contact
method listed on their GitHub profile. Share only enough information in the
initial message to establish a secure channel.

You should receive an acknowledgement within seven days. The maintainers will
investigate, provide status updates when practical, and coordinate remediation
and disclosure. Please allow reasonable time for a fix before public
disclosure.

## Safe-harbor intent

Good-faith research that avoids privacy violations, data destruction, service
disruption, and access to data beyond what is necessary to demonstrate the
issue will be treated as authorized security research for this project. Stop
testing and report immediately if you encounter personal or confidential data.
